# Imersão Google Gemini

Book digital e plataforma de aulas práticas da Imersão Google Gemini com Emerson Mendes, voltada à gestão de micro e pequenas empresas.

## Desenvolvimento local

Requisitos: Node.js e npm.

```sh
git clone <url-do-repositorio>
cd imersaogooglegemini
npm install
npm run dev
```
